# Black Lotus
## If you need help with the tool you can type "python3 blacklotus.py -h" and it will show you all the available options.
Black Lotus is a tool that can be used for pentesting (use only on your own websites or ones you have permission to). It can perform DDoS attacks by sending UDP packets. In it you can also find a simple port scanner that shows you which ports on an IP address are open. The tool is very beginner-friendly and easy-to-use. It is still in early development so do NOT expect a finished tool.
